# YOLOv8-vs-SSD-MobileNetV3-vs-Ensemble-Detec-o-de-EPI-
Este Trabalho de Conclusao de Curso apresenta uma investigação experimental sobre a automação do monitoramento de Equipamentos de Proteção Individual (EPIs) e a identificação de infrações de segurança por meio de Visão Computacional e Aprendizado Profundo. O estudo comparou os detectores de objetos em estágio único YOLOv8n e SSD MobileNet.
